# Checklist da Mala

Checklist de viagem em uma página, sem build: `index.html` puro, salvo no `localStorage`.

- Campo **Dias** define a quantidade das roupas (cuecas, meias e camisas 1 por dia; calças 1 a cada 3; academia 1 a cada 2).
- Toggles **Frio / Calor / Exterior / Aventura** mostram os grupos condicionais.
- Grupos fixos: Roupas, Documentos, Essenciais.
- Adicionar item em cada grupo, remover com ×, restaurar removidos, marcar/desmarcar tudo (só o visível).

Publicado em https://azabraao.github.io/checklist-mala/
